# Security

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's private vulnerability reporting on this repository (Security > Report a vulnerability). We reply within 7 days.

## What each skill runs or sends

plugin-eval-field-notes runs no code, makes no network call and writes no file. It is instructions and reference text only; `references/recipes.md` holds scripts for you to copy and run yourself, and the skill does not run them.

A skill in this repository never sends your files or prompts anywhere. If a future skill needs a script or a network call, this file lists it before release.
